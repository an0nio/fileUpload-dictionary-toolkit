# Content snippets

This folder contains small, copyable payload snippets for manual file content creation.

They are intentionally not generated by a script. Pick the snippet you need, combine it
manually with a valid image, a magic number, or a filename strategy.

## PHP marker

`php/php_funciona.php` prints:

```text
php_funciona
```

The string is stored as base64 in the PHP code:

```text
cGhwX2Z1bmNpb25h
```

## PHP + GIF marker

`php/php_funciona_gif89a.php` starts with `GIF89a` and then prints `php_funciona` if PHP executes.

## PHP introspection

`php/php_introspection.php` prints execution evidence and path information such as `__FILE__`, `realpath(__FILE__)`, and `REQUEST_URI`.

## Handler helper

`php/htaccess_enable_php_for_images.htaccess` is a lab-oriented Apache handler trick for cases where `.htaccess` uploads are possible and `AllowOverride` is enabled.
